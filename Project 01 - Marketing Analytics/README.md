# Data Analytics Portfolio

This repository showcases data analytics projects focused on the 
e-commerce domain, covering the full analytics workflow — from raw 
data exploration to interactive dashboards and actionable business 
insights. The primary focus is translating data into decisions that 
matter to retail and e-commerce stakeholders, such as sales 
performance, customer behavior, and marketing effectiveness.

Each project simulates real e-commerce business questions, using 
Power BI as the primary visualization tool alongside SQL and Python 
for data preparation and analysis.

## What You'll Find Here

- **Sales Performance Dashboards** – Revenue trends, product-level 
  performance, and regional sales breakdowns
- **Customer Analytics** – Customer segmentation, churn analysis, 
  and lifetime value (CLV) insights
- **Marketing & Campaign Analysis** – Conversion rates, funnel 
  analysis, and campaign ROI
- **Cohort & Retention Analysis** – Repeat purchase behavior and 
  retention trends over time
- **Inventory & Operations Insights** – Stock trends, order 
  fulfillment, and demand patterns

## Tech Stack

`Power BI` `SQL` `Python` `Pandas` `DAX` `Excel`

## How This Repo Is Organized

Each project folder contains its own README with the business 
problem, data source, dashboard screenshots/link, key insights, and 
methodology — making every project easy to review independently.

## Purpose

This portfolio demonstrates practical, business-focused analytics 
skills within the e-commerce industry, and serves as a technical 
showcase for potential employers and collaborators.
